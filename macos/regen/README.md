# 作り直す回帰テストの実験（macOS・TextEdit）

AI時代の品質保証戦略の問い5・7（スクリプトを固定しない回帰テスト）を、小さく試した実験。2026-10-15。

## 仕組み

| 部分 | ファイル | 誰が持つか | 変えてよいか |
|---|---|---|---|
| テストケース（意図と期待値） | `testcases/TE-PRINT-001.json` | 人 | **承認が要る**（`approvals.json` のハッシュと違うと実行役が止める） |
| スクリプト（画面との対応表） | `scripts/te_print_ja.py`、`te_print_en.py` | AIが生成 | 作り直してよい |
| 実行役 | `runner.py` | テスト基盤 | 決まったプログラム。AIは入らない。テストケースの手順を順に実行し、操作の記録（`runs/<label>/log.json`）を残す |
| 比較 | `compare.py` | テスト基盤 | 2回の操作の記録を比べ、ユーザーから見て同じテストをしたかを判定する |
| 承認 | `approve.py` | 人 | テストケースの版を承認する |

ポイント：**手順はテストケースから来る**ので、スクリプトを作り直しても手順を飛ばすことはできない。スクリプトが決めるのは「意味の名前（部数、横向き…）を、画面のどの部品に結びつけるか」だけ。

```
./.venv/bin/python regen/approve.py regen/testcases/TE-PRINT-001.json <承認者>
./.venv/bin/python regen/runner.py --testcase regen/testcases/TE-PRINT-001.json --script regen/scripts/te_print_ja.py --lang ja --label ja-2 --no-shots
./.venv/bin/python regen/compare.py ja-2 en-3
```

`--lang en` でTextEditを英語で起動し、「画面が変わった」状況を作る。`--no-shots` はスクリーンショットを撮らない（撮る場合はClaudeアプリへの画面収録の許可が要る）。

## 結果

| 実験 | 結果 | 分かったこと |
|---|---|---|
| 日本語のスクリプトで、日本語の画面（基準） | 合格 | — |
| 日本語のスクリプトで、英語の画面 | 手順1で失敗 | ラベルに頼るスクリプトは、言語（文言）が変わると壊れる |
| **作るモード**：英語の画面構造をダンプして、AIがスクリプトを作り直す | 合格。比較は「**同じテストをした**」 | スクリプトが変わっても（部数→Copies など）、ユーザーから見た操作と確認は同じだと機械で判定できた |
| テストケースの期待値を、承認なしで変える | **実行役が止めた** | 期待値を人が持つ仕組みは働く |
| AIが部品を取り違える（横向き→縦のボタン） | **合格してしまった**。比較も「同じテストをした」 | **偽の合格**。押すのも確かめるのも同じ取り違えた部品なので、操作の記録の比較では見抜けない |
| 対策：テストケースに反対側の確認（縦向き＝0）を足し、承認し直す | 取り違えたスクリプトは**手順9で失敗**。正しいスクリプトは日本語・英語とも合格 | 期待値の設計で、部品の取り違えを見抜ける |

### 途中で見つかったこと

- **環境の準備は実行役の仕事**：英語で起動したとき、前回の書類が復元され、「開く」パネルが出ずにテストの前提が崩れた。起動時に状態を復元しない設定（`-ApplePersistenceIgnoreState YES`）を実行役に入れて解決。スクリプトの問題ではなく、環境の初期化の問題
- **画面収録の確認ダイアログ**：スクリーンショットを撮ると、macOSの確認ダイアログが前面に出て、キー操作（Cmd+P）がアプリに届かなくなった。実行役は、画面の前面を奪うものがない環境で動かす必要がある
- **実行役自身のバグ**：「印刷シートが閉じているか」の判定に誤りがあり、最初は常に「開いている」と判定していた。基盤の側の品質も、テストの結果に直結する

## 部品の取り違え（偽の合格）への対策

この実験で最も大事な発見。操作の記録の比較は「同じ手順を踏んだか」は保証するが、「正しい部品を操作したか」は保証しない。

| 対策 | 中身 | この実験 |
|---|---|---|
| **反対側の確認を期待値に入れる** | 「横を押したら縦は外れる」のように、取り違えると矛盾する確認を足す | 試した。効いた |
| **IDを使う** | 言語に依存しないIDなら、翻訳での取り違えが起きにくい | TextEditの印刷シートには明示的なIDがない |
| **対応表をレビューする** | 作り直した対応表（横 → Landscape）を、作ったAIとは別のAIか人が確かめる | 未実施 |
| **画面写真で確かめる** | 操作の前後の画面をAIが見て、意味が合っているかを確かめる | 未実施（画面収録の許可が要る） |
| **良品ビルドで回す** | 作り直したスクリプトを、合格済みのビルドで回す | この取り違えは良品でも合格するので、**見抜けない**。良品での確認は万能ではない |
